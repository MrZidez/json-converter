# 🚀 HAPP Config Converter

Конвертер VLESS, Hysteria2, Trojan, VMESS, Shadowsocks ссылок в JSON для HAPP.

## 🌐 Сайт

**[VPN From Kirill](https://github.com/MrZidez/free-sub)**

## 🛠️ Установка

```bash
git clone https://github.com/MrZidez/vpn-converter.git
cd vpn-converter
pip install -r requirements.txt
python app.py
```

📦 Сборка .exe
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name="HAPP_Converter" --add-data="index.html;." --add-data="style.css;." --add-data="script.js;." --add-data="logo.jpg;." app.py
```
